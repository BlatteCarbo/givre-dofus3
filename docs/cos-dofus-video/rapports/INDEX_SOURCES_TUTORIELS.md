## Sources de vérification des données et versions

- [Dofus Grimoire, les 19 classes](https://dofus-grimoire.fr/classes/) : guides déclarés pour DOFUS 3.7.12 (correctif daté du 20 octobre 2026) ; données et combos à vérifier avant utilisation en code.
- [OpenDofusDB](https://openddb.dev/) : index de 19 classes, sorts, monstres et objets issus des données du jeu, non officiel ; vérifier version des tables exportées.
- [Journal OpenDofusDB 3.7.13.17](https://openddb.dev/changelog) : données communautaires indiquées **extraites le 3 novembre 2026**, comparaison à 3.7.12.12. L'existence du changelog ne remplace ni l'audit des 19 listes de sorts de cette build, ni le résultat réel d'un sort en combat.
- [Back from AFK](https://backfromafk.com/) : comparaisons 3.3–3.7 et changements de sorts par classe ; utile pour écarter les vidéos obsolètes.
- [Xawpiya, index vidéo](https://xawpiya.fr/videos/) : découverte de plusieurs duos 2026, renvoi YouTube ; le titre seul ne prouve pas une mécanique.
- [Dofus Grimoire, catalogue des boss](https://dofus-grimoire.fr/boss/) : point de départ pour les machines à états d'invulnérabilité, à documenter boss par boss.
