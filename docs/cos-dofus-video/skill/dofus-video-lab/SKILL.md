# Dofus video lab

Utilise ce skill lorsque l'utilisateur demande de tirer des connaissances de combat de videos Dofus pour GivreClone.

1. Localise le kit `docs/cos-dofus-video` dans le projet CoS actif. Le chemin de preparation est `%USERPROFILE%/.t3/worktrees/GivreWork/fix-f01-f16-final-20261024/docs/cos-dofus-video`. Si ce chemin n'est pas accessible, demande l'acces au kit ou son contenu ; ne suppose pas que les outils peuvent sortir des racines approuvees.
2. Lis `PROMPT.md` pour la procedure et `MODELE_FICHE.md` pour les livrables. Lis `OUTILS.md` seulement si un outil manque ou si la collecte echoue.
3. Applique la mission aux liens et au sujet donnes par l'utilisateur. Ecris les fiches et la synthese uniquement dans `rapports/` du kit. Le prompt fait autorite sur la methode ; ce skill est son point d'entree, pas une seconde version.
4. Termine avec les chemins des rapports, la couverture reelle et les regles encore non verifiees. La collecte ne vaut ni validation du code ni validation en jeu.
