## UI test regressions (2026-11-07, status at end of the reviewed window: not yet re-verified)

- After the Streamer ("Discret") privacy work, the full UI suite showed 13 failures in Expedition layout, Bots keyboard tabbing, and compact Bots captures. Removing the new "Discret" badge did not change the 13 failures, so they predate that badge.
- Root causes found in the UI tests' lookups: 17 top-level BotsView tabs had lost their `Tag` attributes, which broke Ctrl+K, Alt+Left, and tab-selection-by-Tag tests. The Tags were restored in catalog order. Expedition controls had lost the names the layout test expects (ExpeditionLayout, ExpeditionSettings, ExpeditionDetails, ExpeditionStartButton, ExpeditionStopButton); names were restored without changing the layout. The challenge-abandon threshold input had lost its class and accessible name; its name now comes from the existing "abandon de défi" label.
- Compact-capture failure after that was a width overflow of `bots/tabs/0/3`, not a missing name (the Remote names already existed in SettingsView).
- Lesson: when a UI test fails, check whether the failure predates your change by temporarily removing your change and re-running the same tests. Treat missing `Tag` / name attributes as a common cause of selector-based UI test failures.
- Streamer-privacy: three character names in BotsView lacked the `pii` class and were given it. Whether the Streamer masking is complete was not verified in the window.
