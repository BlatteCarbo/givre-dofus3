# Expedition failure policy

On 2026-11-05, the user selected “Oui, distinguer les causes” for this proposed behavior: continue to the next map when no monster group matches the configured filters; for a map that is not ready or a refused movement, retry in a bounded way and then stop with the precise reason. This is a confirmed intended behavior, not evidence that implementation or live validation is complete. Preserve group filters and distinguish no-target results from technical failures.
