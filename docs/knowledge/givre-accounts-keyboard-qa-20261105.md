# Accounts keyboard navigation QA — 2026-11-05

A compact Avalonia headless test found Tab and Shift+Tab could focus controls outside the window in populated Accounts. The initial diagnosis blamed vertical scrolling; detailed coordinates showed horizontal overflow: the actions row measured 752 px in a 720 px window. The ineffective focus-handler attempt was removed. A constrained horizontal scroll/reveal behavior for that row fixed the actual layout issue.
