# Dofus Enhanced : apports utiles à GivreClone

Lecture seule le 23/10/2026, aucun outil ni binaire du dépôt exécuté. Référence consultée : commit `509a92538acfb97b746c291c359bc9d356e6dcb8` ; [README](https://github.com/Altansar69/dofus-enhanced/blob/509a92538acfb97b746c291c359bc9d356e6dcb8/README.md), [guide](https://github.com/Altansar69/dofus-enhanced/blob/509a92538acfb97b746c291c359bc9d356e6dcb8/docs/GUIDE.md), [panneau du carnet](https://github.com/Altansar69/dofus-enhanced/blob/509a92538acfb97b746c291c359bc9d356e6dcb8/src/notebook/notebook-panel.cpp). Réimplémentation Avalonia, sans copier de code natif.

Le carnet, les trajets, les ressources cartographiques, la chasse et une partie des options visuelles existent déjà dans GivreClone. Les propositions ci-dessous portent sur les compléments observés, pas sur une recréation de ces modules.

| Complément absent ou incomplet | Intérêt | Faisabilité MITM / Socket | Fichiers concernés et statut |
|---|---|---|---|
| Carnet compact, formulaires masqués sans perdre les brouillons | Consulter positions, notes et messages en gardant plus de place | Interface locale identique dans les deux modes | **Implémenté** : `Views/EcoToolsPanel.axaml`, `ViewModels/EcoToolsViewModel.Notebook.cs`. Choix conservé pendant la vie du panneau, pas entre lancements. |
| Recherche commune du carnet, sans accents, par plusieurs mots ou coordonnées | Retrouver une entrée dans un carnet fourni | Interface locale, aucun paquet | **Implémenté** : mêmes fichiers et `Services/Eco/NotebookSearch.cs`. Adaptation complémentaire de l'idée de carnet de Dofus Enhanced. |
| Carnet partagé : relecture externe et résolution des modifications concurrentes | Ne pas écraser une entrée modifiée depuis un autre client | Stockage local dans les deux modes ; nécessite une gestion des versions du fichier | À prévoir : `Services/Eco/EcoStores.cs`, `ViewModels/EcoToolsViewModel.Notebook.cs`. Le fichier JSON actuel n'a pas d'identifiants ni de version d'entrée. |
| Repères du carnet sur la carte avec dimension explicite | Différencier deux positions [x,y] de mondes différents | MITM et Socket : rendu local à partir des données de carte observées | À prévoir : `Services/Eco/EcoStores.cs`, `Services/WorldAtlas/*`, `Controls/RouteMapControl.cs`, `Views/EcoToolsPanel.axaml`. Exige de faire évoluer les positions et leur migration, au-delà d'un habillage. |
| Mode Ocre : manquants par zone, en distinguant quête, sac et Metamob | Réduire les recherches d'archimonstres déjà possédés | Les deux modes peuvent exploiter les événements de quête et effets des pierres ; Metamob demande une intégration API explicite | À prévoir : `Services/LotM/GameDb*.cs`, `Services/QuestProgression/*`, nouveau service Ocre et nouvelle vue. Ne pas confondre pierre vide et âme capturée ni supposer la banque connue. |
| Badges « âme en sac » et progression Ocre sur les liens du chat | Évaluer un monstre partagé immédiatement | Rendu identique ; dépend de l'index d'âmes et du suivi Ocre ci-dessus | À prévoir après l'index : `Controls/ChatMessageText.cs`, `Services/Chat/*`. Ne pas produire un faux « absent » quand le sac est inconnu. |
| Événements Kralamoure Metamob dans le calendrier | Planifier les ouvertures sans changer d'outil | API externe, faisable dans les deux modes ; pas de paquet de combat | À prévoir : nouveau service calendrier Metamob, `Services/SeasonalCalendar.cs`, vue calendrier. Mise en cache, fuseau local et configuration nécessaires. |
| Téléportation au conjoint avec distance et disponibilité | Raccourci de déplacement pertinent | MITM : état observé puis demande au clic ; Socket : mapping et préconditions serveur à vérifier | À transmettre à Claude : `Services/LaunchService.Movement.cs` et `Services/GivreLuaHost.Travel.cs` sont réservés ; interface dans les vues de groupe. |

Les modifications de rendu du client natif (miniatures, suppression des animations, contours à travers les murs, préchargement des cartes) ne se transposent pas en simple interface Avalonia. Le mode Socket n'a pas de client graphique auquel appliquer ces options. Les options déjà présentes ne sont donc pas présentées comme des fonctionnalités manquantes.

Vérification des ajouts : Atelier éco → Carnet, créer plusieurs entrées, chercher « ile » dans un texte contenant « Île », chercher plusieurs mots répartis entre titre et note, activer/désactiver Vue compacte avec un brouillon saisi. Les entrées et le brouillon restent présents ; les boutons de copie gardent leur fonctionnement local.
