## Base de données réellement raccordée

Source : [ledouxm/dofus-sqlite, release v6.0_3.7.11.11](https://github.com/ledouxm/dofus-sqlite/releases/tag/v6.0_3.7.11.11).
Identité de release, tailles et SHA-256 des assets vérifiés. Cela prouve la provenance des octets, pas les réponses du serveur de jeu.

- SQLite : `bcb66ca4611bdff29c5e303cb4dd4770790c6c4905e6a81b0e8c2a33726501b7`.
- Lecture par le vrai `GameDb` : 23 métiers, 4 743 recettes, traductions présentes ; hash inchangé après fermeture.
- TSV : 20 784 objets, un objet sans type exclu explicitement ; toutes les valeurs exportées comparées indépendamment à la base.
- DLL finale : `4bb3076604a5f077e5cb6717c39805a1d9645293d603348bd9aea3b0e9df938a`, identique dans le paquet Debug et dans l'empreinte de `NativeTurboRuntime`.
- Installation locale dans `%LOCALAPPDATA%/GivreReplica/TestRuns/givre-app-offline/userdata/gamedata/dofus.sqlite`. Ce fichier était absent ; aucun dataset existant remplacé. Le résolveur `GameDb.Locate` le découvre au prochain démarrage, sauf surcharge explicite `GIVRE_GAMEDATA`.
- Les téléchargements restent dans `artifacts/round6-prompt2-release`, hors Git ; table dérivée, provenance et générateur sont versionnés. Aucun compte ni secret lu pour cette installation.
