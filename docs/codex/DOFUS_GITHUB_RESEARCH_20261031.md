## Decision

**Use Monture Minute as the first breeding-domain reference and D3B as the first C#/Avalonia UI reference.** Add a local, event-driven HDV/FM journal inside Givre rather than launching another capture service. Prospection is the richest functional reference for that journal, but it does not grant a reusable source license and explicitly requests non-distribution. For cosmetics, the discovered Skinator is **Retro 1.49.7**, not a Dofus 3 renderer. Dofus Forge is a better permissively licensed item/rune reference, but not a live FM overlay. These are engineering recommendations inferred from the evidence below.

## Method and limits

Used official GitHub repository metadata, default-branch latest commits, releases, recursive trees, READMEs, dependency manifests, licenses, and selected implementation files. Exact timestamps below are **commit committer dates**, not repository `updated_at` or push dates. Release dates are `published_at`; no release means the public releases API returned an empty array. Dates are all UTC and none is after the research date. Source inspection establishes implemented paths, not successful runtime behavior. No project was built or run; idle costs below are qualitative engineering estimates unless a code timer is given.

Fresh discovery used GitHub repository search in two waves: general Dofus updated since 2026-10-01 plus breeding, then targeted overlay/forgemagie/skin/HDV since 2026-09-01. Six useful additional candidates were inspected. Download-promotion repositories were excluded. Discovery is not exhaustive.

Public visibility alone is not a source reuse grant: GitHub's own guidance explains the default restrictions when a license is absent. "No license found" below means no project license in the inspected root/tree/README/API, not a definitive authorship determination. MIT notices must be retained; game assets have separate ownership. [GitHub licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).

## Ranked concrete recommendations

1. **Breeding now:** design one native paddock card with current gauges, one next action, estimated finish and refill times. Port Monture Minute's licensed domain engine/tests, then feed observed Givre state into it. Distinguish simulated values from last-observed values and allow manual correction. Do not import its Expo/Electron runtime. [S2]
2. **Native shell now:** study D3B's Avalonia cards, activity/log/map separation, profile editor and localization. Adapt only the view/viewmodel patterns that fit Givre; avoid an engine/relay migration or a second bot host. Check Givre's actual Avalonia/.NET versions before selecting any source files. [S4]
3. **HDV/FM next:** create per-item observed lot prices, timestamp/server, asking-price versus confirmed-sale distinction, exo/over classification, and an FM session journal. Prospection supplies the most relevant behavior reference; Astrub supplies MIT parsing evidence. Use Givre's event stream and local SQLite, not another Npcap process or Python web stack. Obtain permission before copying Prospection. [S7, N1]
4. **Long-term breeding collection:** use owned/needed/parent-pair graph and generation shopping plan from the dofus_montures feature model; it solves a different problem from daily gauge timers. Treat its greedy strategy as a heuristic, not an optimality guarantee, and resolve permission before code reuse. [S6]
5. **FM model/reference library:** use Dofus Forge's licensed rune/item structures for target configuration. Study MagusCode for presets/sink-oriented workflow only; do not advertise its MagusWin stub as a working native FM bot. [N2, N3]
6. **Cosmetics later:** prototype a native outfit comparison/saved palettes panel using version-correct Dofus 3 assets only. Skinator demonstrates valuable team/compare/export UX but cannot provide a Unity renderer. Penombre can remain an optional separate GPL tool for visual atmosphere rather than being folded into a differently licensed application. [N5, S3]
7. **Defer coordinate OCR and separate craft servers:** resource assistant duplicates information Givre likely already observes; dofus-job is useful once a concrete crafting-planner requirement exists, not a first priority for breeding/FM. This conclusion assumes Givre already exposes coordinates, market messages and inventory; those contracts were not inspected in this child. [S1, S5]
