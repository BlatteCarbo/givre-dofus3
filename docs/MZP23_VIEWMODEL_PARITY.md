**Méthode (reproductible).** Copie isolée de `GivreClone.exe` lancée avec un profil APPDATA séparé (sans connexion), dump mémoire complet via `dbghelp MiniDumpWriteDump` (`GivreSandbox/dump_pid.ps1`), extraction des chaînes ASCII, puis lecture des métadonnées de *bindings compilés Avalonia* (`GivreClone.App.<ns>.<Type>,GivreClone.<Membre>!Property|Getter|Setter|Field`).
